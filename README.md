# 新媒体内容发布工作台（Media Content Workbench）

覆盖 **4 个短视频平台（抖音 / 快手 / 小红书 / 视频号）+ 6 个文书平台（百家号 / 公众号 / 知乎 / 企鹅号 / 搜狐号 / 官网）** 的内容登记、数据复盘与账号管理工具。

纯前端 + Node 文件存储，**零第三方依赖**，可离线安装为 PWA 使用。

---

## ✨ 功能总览

| 模块 | 说明 |
|---|---|
| 📅 **今日发布** | 今日发布概览（短视频/文书/总登记/平台覆盖）+ 平台数据表格解析 |
| 📝 **内容登记** | 内容登记/编辑/删除、标题/选题/链接、搜索（回车触发）、日期+平台+播放量筛选、数据录入 |
| 🎯 **账号登记** | 4 平台账号 ID/备注登记（一平台多账号）、账号数据快照（发布量/粉丝量/播放/点赞/评论/转发）、绑定具体账号、粉丝趋势、与上次记录对比 |
| 📊 **数据复盘** | 短视频数据（周/月切换、平台播放对比柱形图、播放趋势折线图带峰值标注、点击跳转发布日历）、文书 AI 收录追踪（6 大引擎 ✓ 收录）、周/月复盘登记 |
| 🗓️ **发布日历** | 按月查看每日 10 平台发布任务，点击日期查看详情 |
| 📈 **发布总览** | 月度总览统计（发布数/播放/点赞/评论/涨粉/收录） |

### 核心能力

- **表格解析导入**：上传平台导出的 xlsx 或粘贴表格文本，自动识别列（标题/日期/播放/完播率/均播时长/点赞/评论/收藏/推荐/分享/涨粉/AI收录），小红书空标题笔记以「空标题」占位录入，自动关联内容登记
- **导入乱码检测**：检测非 UTF-8 源文件导致的乱码（U+FFFD）与非法平台名，导入/解析后即时警告
- **多格式导出**：全部/本周/本月 三个周期，点击后弹窗选择「Excel 表格（.xls，可手动修改）」或「HTML 格式（Ctrl+P 打印/导出 PDF）」，另支持 JSON 全量备份/导入恢复
- **账号体系**：账号 ID 一平台多账号；账号数据绑定具体账号（同平台不同账号独立记录/汇总/趋势/对比），历史数据归「未指定账号」
- **PWA 离线安装**：可安装为桌面应用，Service Worker 缓存前端壳，数据接口实时不走缓存

## 🚀 快速开始

### 环境要求

- **Node.js**（≥ 14 即可，仅使用内置模块，无需 `npm install`）

### 启动方式（任选其一）

```bash
# 方式一：双击
StartWorkbench.bat

# 方式二：命令行
npm start        # 等价于 node start-ui.js（带交互启动器）

# 方式三：直接起服务
node server.js   # 纯静态 + API 服务
```

启动后访问 **http://localhost:3000**（端口可用环境变量 `PORT` 覆盖；端口被占用时启动器自动复用已有服务）。

### 安装为桌面应用（PWA）

浏览器打开工作台 → 地址栏右侧「安装」图标（或 设置 → 应用 → 安装「新媒体工作台」）。安装后可离线使用。

## 📦 数据存储

后端为每个数据 key 存一个 JSON 文件（`/api/data/{key}` 读写，原子写入 + 同 key 串行化防竞态，共 6 个 key）：

| key | 文件 | 内容 |
|---|---|---|
| `contents` | `data/contents.json` | 内容登记（标题/平台/选题/链接/日期） |
| `stats` | `data/stats.json` | 短视频单条数据（播放/完播/均播/点赞/评论/收藏/推荐/分享/涨粉） |
| `aiStats` | `data/aiStats.json` | 文书 AI 收录（6 引擎 ✓ 状态） |
| `reviews` | `data/reviews.json` | 周/月复盘记录 |
| `accountStats` | `data/accountStats.json` | 账号数据快照（绑定 accountRef，当天=最新总数据） |
| `accountIds` | `data/accountIds.json` | 视频平台账号 ID/备注（一平台多条） |

> ⚠️ **`data/` 目录已被 `.gitignore` 忽略**——数据不会进入 Git 仓库。迁移/备份时请单独拷贝 `data/` 目录，或在界面「导出 JSON」做全量备份（含全部 6 类数据）。

## 📤 导出与导入

### 导出数据（顶部按钮「导出数据 ▾」）

- **全部数据 / 本周数据 / 本月数据** → 点击后弹窗选择：
  - **Excel 表格**：下载 `.xls` 报表（HTML 表格格式，可手动修改、可打印）
  - **HTML 格式**：新窗口打开网页报表，`Ctrl+P` 直接打印或导出 PDF
- **导出 JSON**：全量备份（7 类数据 + 各 key 条数提示），可跨机器恢复
- **打印预览**：任何周期均可新窗口预览后打印

### 导入恢复

- 「导入恢复」选择之前导出的 JSON 文件 → 覆盖恢复全部数据（旧版含 tasks 的备份仍可导入，tasks 字段自动忽略）
- 导入后 toast 显示各 key 条数，并自动检测乱码记录

## 🔄 迁移指南

1. **整目录拷贝**：连同 `data/` 一起拷贝整个项目文件夹到新机器（目标机装 Node 即可，无 npm 依赖）
2. **远程/跨设备**：工作台「导出 JSON」→ 新机器「导入恢复」（推荐，数据为快照式）
3. Git 拉取代码**不含数据**（`data/` 被忽略），如需同步数据请单独处理

## ⚠️ 注意事项

- **端口**：默认 3000，`PORT` 环境变量可改；启动器检测到端口被占会自动复用已有服务
- **PWA 缓存**：改动前端代码后需同步升级 `index.html` 里的 `?v=` 版本号与 `sw.js` 的 `CACHE` 版本（v5），否则浏览器可能拿旧壳；数据接口（`/api/`、`/data/`）永远实时不走缓存
- **表格导入编码**：建议优先使用 **xlsx**（强制 UTF-8）；使用文本粘贴/上传时，若源文件为 GBK/ANSI 编码会导致中文乱码，系统会检测并警告，请另存为 UTF-8
- **账号数据记录方式**：账号数据为「不定时快照」——当天记录即该账号最新总数据，与上次记录自动对比（正绿负红）
- **无每日任务概念**：页面不做每日任务生成与完成统计；发布情况以「内容登记」为准（日历、今日发布、总览均基于登记数据）
