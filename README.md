# 新媒体数据工作台

> **当前版本：v3.2.1** — AI 功能页改为左右独立分栏面板、整体容器加宽、账号登记页移除粉丝趋势图；工作台下拉改名「🤖AI功能」

覆盖 **4 个短视频平台（抖音 / 快手 / 小红书 / 视频号）+ 6 个文书平台（百家号 / 公众号 / 知乎 / 企鹅号 / 搜狐号 / 官网）** 的内容登记、数据录入、复盘分析、AI 智能分析与账号管理一体化工具。

适合新媒体运营人员每天使用：登记发布了什么 → 录入平台数据 → 查看趋势与复盘 → AI 自动分析 → 导出汇报。

**技术亮点：零第三方依赖**——后端仅用 Node.js 内置模块（http/fs/path），前端不引入任何第三方库，安装 Node.js 即可运行。

## 一、功能总览

工作台共 6 个页面（顶部标签切换）：

| 页面 | 功能 |
|---|---|
| **今日待办** | 今日发布概览（短视频/文书/总登记/平台覆盖）；各平台「+1」快速登记；平台直达快链（视频/文书/AI 三组，可自定义） |
| **内容登记** | 登记每条内容的标题/平台/选题/链接/日期；搜索（回车或点按钮）、按日期/平台/播放量筛选；每条内容可录入播放、完播率、均播时长、点赞、评论、收藏、推荐、分享、涨粉等数据；平台数据表格解析（上传平台导出的表格自动识别并录入） |
| **账号登记** | 视频平台：账号 ID / 备注 / 登录手机号 / 实名人 / 运营人（一个平台可多个账号）；账号数据快照（发布量/粉丝量/播放/点赞/评论/转发），数据绑定到具体账号，每条数据与上一条记录的升降对比箭头。文书平台：账号 ID / 备注 / 登录手机号 / 实名人 / 运营人登记 |
| **数据复盘** | 短视频数据看板（周/月切换、播放对比柱形图、趋势折线图带峰值标注，点击数据点直达发布日历）；文书 AI 收录追踪（6 大引擎收录状态）；周/月复盘记录 |
| **发布日历** | 按月查看每天各平台发布情况，点击日期看当日内容明细；法定节假日标记（2026-2028 年，含元旦/春节/清明/劳动节/端午/中秋/国庆） |
| **发布总览** | 月度汇总（本月数据总览 + 各平台数据占比饼图 + 各平台发布明细），按视频/文书分区显示；支持按月切换查看 |

### 核心能力

- **AI 大模型接入**：配置 OpenAI 兼容接口（DeepSeek/豆包/千问/文心等），支持 AI 生成视频描述与 AI 数据总结分析，每日额度管理（chat/review 独立计数，每类每日 20 次上限）
- **AI 数据总结分析**：选择分析对象（视频平台/文书平台）与周期，自动汇总数据，调用大模型生成结构化分析报告（总体表现/亮点/问题/建议），支持导出 Word 文档
- **表格一键解析**：上传平台导出的数据表（xlsx/csv/tsv/txt），自动识别列并录入数据；小红书空标题笔记自动占位；非平台表格会被自动拦截
- **数据自动关联**：内容登记 ↔ 平台数据 ↔ 发布日历 相互关联，录一次数据全站联动
- **多格式导出**：全部/本周/本月三个周期，可选「Excel 表格」或「HTML 网页（可直接打印/存 PDF）」
- **AI 分析导出**：分析结果导出为 Word 文档（.doc，HTML 格式，页面视图，UTF-8 BOM）
- **全量备份恢复**：一键导出 JSON 全量备份（含全部数据），换电脑/迁移时一键导入恢复
- **桌面应用**：支持安装为桌面应用（PWA），离线也能打开
- **平台直达快链**：今日待办页三组快捷链接（视频平台/文书平台/AI 平台），支持自定义编辑

### 指标显示规则（视频数据栏）

| 情况 | 显示 |
|---|---|
| 平台不适用（如快手不记均播、小红书不记完播率、视频号不记收藏） | `-` |
| 适用但未录入 | 留空 |
| 适用且录入 0 | `0` |
| 适用且录入数值 | 格式化数字（如 `1.2w`） |

## 二、快速开始

### 环境要求

- Windows / macOS / Linux 电脑，安装 **Node.js ≥ 14**（无需安装任何依赖包，也不需要 Python）

### 启动方式（Windows，推荐：桌面快捷方式）

日常打开工作台，**只需要双击桌面上的「新媒体数据工作台」图标**：它会自动在后台启动服务并打开浏览器，全程**不弹黑窗口**。

首次使用需要先创建这个桌面图标（见下方「创建桌面快捷方式」）。

#### 创建桌面快捷方式（只做一次）

1. 打开项目文件夹（解压后的位置）
2. **双击 `CreateShortcut.bat`**，出现一行 `OK: shortcut created` 即成功
3. 桌面出现 **「新媒体数据工作台」** 图标 → 以后双击它即可启动

> - 该脚本**不依赖任何东西**（不需要安装 Python），任何 Windows 电脑都能用；内容为纯英文编码、中文以编码内嵌，**任何电脑上运行都不会乱码**
> - 换电脑 / 移动项目文件夹后，旧快捷方式会失效：重新双击一次 `CreateShortcut.bat` 即可重建（不影响 `data/` 里的数据）

#### 双击桌面图标后发生了什么（启动路径）

```
桌面快捷方式「新媒体数据工作台」
  └─ 指向 Start.bat（一键启动脚本）
       ├─ 调用 start-hidden.vbs → 后台隐藏启动服务（node server.js，无窗口、不占用命令行）
       └─ 等待服务就绪 → 用默认浏览器打开 http://localhost:3000
```

> 服务会一直在后台运行（不占用任何窗口）。关掉浏览器页面**不影响服务**，数据照常保存；再次双击快捷方式即可重新打开页面。

### 启动（Windows，备选）

没有快捷方式时，也可直接双击 **`Start.bat`**（效果与桌面快捷方式完全一致：服务后台隐藏运行、浏览器自动打开）。

- 端口默认 **3000**；服务已在运行时重复启动会自动复用
- 出问题排查用 **`ViewStart.bat`**（前台运行，服务日志直接显示在窗口，Ctrl+C 停止，窗口不自动关闭）

### 启动（macOS / Linux）

```bash
node server.js
# 浏览器访问 http://localhost:3000
```

### 安装为桌面应用

浏览器打开工作台 → 地址栏右侧「安装」图标 → 安装「新媒体数据工作台」。之后可从桌面图标直接打开，离线可用。

## 三、AI 大模型功能

所有 AI 功能集中在导航栏右侧下拉的「**🤖AI功能**」页：上方配置大模型，下方「AI 生成视频描述」与「AI 数据总结分析」两个功能块，各为**左右独立分栏面板**（左栏=参数设置/标题/说明，右栏=AI 输出结果，两栏等高分离）。

### 配置入口

导航栏右侧下拉 → 「🤖AI功能」→ 填写 API Key（密码框，页面从不渲染真实 Key）→ 保存后锁定，测试连接验证可用性。

支持 OpenAI 兼容接口：DeepSeek、豆包、千问、文心、元宝、纳米等。

### AI 生成视频描述

选择平台 + 填写选题/主题（可选行业卖点），一键生成 3 个标题、视频描述与推荐标签，点击即可复制，结果可一键清空。

### AI 数据总结分析

选择分析对象（视频平台 / 文书平台）与总结周期（全部 / 本月 / 本周），点击「AI 数据分析」：

1. 自动汇总该分析对象选定周期的数据（视频/文书指标各自独立计算、结果分开保存）
2. 调用大模型生成结构化分析报告（总体表现 / 亮点 / 问题 / 下一步建议）
3. 回复后可「导出为 Word」生成 .doc 文档（页面视图，Word 可直接打开）

### 额度管理

- 每类每日上限 20 次（chat 生成视频描述 / review 数据总结分析独立计数）
- 跨天自动重置
- 额度用尽时 AI 功能按钮自动禁用

## 四、日常使用流程

```
1. 今日待办 → 各平台 [+1] 登记今天发布的内容
2. 内容登记 → 补全标题/选题/链接，逐条录入平台数据（或直接上传平台导出的数据表一键解析）
3. 数据复盘 → 看周/月趋势与峰值，做复盘记录
4. 🤖AI功能 → AI 数据总结分析，一键生成报告并导出 Word
5. 导出数据 → Excel 汇报 或 HTML 打印存档
```

### 数据导入（表格解析）

1. 内容登记页 → 「解析数据表格」→ 选择数据所属平台
2. 上传该平台导出的表格文件（或粘贴表格文本）
3. 系统自动识别表头并暂存预览 → 确认无误点「导入解析」
4. 内容自动登记 + 数据自动填充，并同步到发布日历

> 提示：优先用 xlsx 文件（编码安全）；文本粘贴时若源文件不是 UTF-8 编码，系统会检测并警告。

### 数据导出

「导出数据」→ 选周期（全部/本周/本月）→ 弹窗选格式：

| 格式 | 用途 |
|---|---|
| **Excel 表格** | 下载 .xls 报表，可手动修改、可打印 |
| **HTML 网页** | 浏览器直接打开，Ctrl+P 打印或另存为 PDF |

导出内容根据数据自动裁剪：无数据的栏位（视频平台账号数据/文书平台账号登记）自动隐藏。

「导出 JSON」用于全量备份；「导入恢复」用于还原备份。

## 五、数据与备份

工作台所有数据保存在项目目录 **`data/` 文件夹**（7 类数据：内容登记、视频数据、文书收录、复盘记录、账号数据、账号 ID、文书平台账号）。

| 备份方式 | 适用场景 |
|---|---|
| 「导出 JSON」+ 他机「导入恢复」 | 换电脑 / 远程迁移（推荐，简单可靠） |
| 直接拷贝 `data/` 文件夹 | 整盘迁移 / 同机备份（需先停服务） |

> ⚠️ 注意：`data/` 目录不随代码仓库同步（已自动忽略）。迁移时**务必单独带上数据**，否则新环境只有空壳没有数据。

## 六、技术架构

### 零依赖设计

- **后端**（`server.js`）：Node.js 内置模块实现静态文件服务 + JSON 数据读写 API
  - `GET  /api/data/{key}`：读取数据（不存在返回 `[]`）
  - `POST /api/data/{key}`：单键写入（**原子写**：先写临时文件再 rename 替换，中途关窗不留半截文件）
  - `POST /api/data/batch`：批量写入（**两阶段提交 + 失败回滚**：先全部写 tmp、再全部 rename；中途失败时已替换文件用旧内容还原、未替换的删 tmp，尽量保持跨文件一致）
  - **缓存自动刷新**：js/css 按内容计算哈希指纹自动注入 `?v=`，改代码后浏览器必然拿到新文件，无需手动维护版本号；带指纹资源配 `immutable` 长缓存，`index.html` 走 `no-cache`
- **前端**：原生 JS + CSS，无框架、无构建、无 npm 依赖

### 安全设计

- **XSS 防御**：所有用户输入经 `escapeHtml()` 转义；链接经 `safeUrl()` 仅放行 http/https；自动化回归测试验证运行时渲染安全
- **路径安全**：静态文件服务禁止路径穿越、禁止直接访问 `data/` 目录（数据只走 API）
- **乱码检测**：导入后自动扫描关键文本字段，识别 U+FFFD 乱码并提示
- **API Key 安全**：页面从不渲染真实 Key，编辑留空=保持原 key，密码框输入

### 手写 xlsx 解析

不依赖任何第三方库，自行实现 ZIP 解压 + sharedStrings + sheet XML 解析，支持 xlsx/csv/tsv/txt 多格式表格导入。

### PWA 离线支持

Service Worker 采用「数据请求永远走网络 + 静态资源 stale-while-revalidate」策略，安装后离线可用。

## 九、常见问题

- **服务断线提示**：页面顶部提示「后台服务已断开」→ 用 `ViewStart.bat` 重新启动即可（数据不会丢）
- **桌面快捷方式失效/打不开**：项目文件夹被移动或换电脑后，旧快捷方式会指向不存在的位置；重新双击一次 `CreateShortcut.bat` 即可重建（不影响 `data/` 里的数据）
- **端口被占用**：设置环境变量 `PORT=3001` 后再启动，浏览器访问新端口
- **手机也想用**：手机连同一 WiFi，浏览器访问 `http://电脑IP:3000` 并「添加到主屏幕」；需在外面访问可另配内网穿透（Tailscale 等）
- **换电脑迁移**：旧机「导出 JSON」→ 新机装 Node + 启动 → 「导入恢复」
